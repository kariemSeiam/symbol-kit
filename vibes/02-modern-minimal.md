# 02 — Modern Minimal

> Stripe, Linear, Vercel. No borders, no noise. Filled dots, pills, middle-dot separators. Every element breathes.

## Signature

`● ○ ▰▱ · → ↗`

## Philosophy

Modern-minimal removes everything that does not carry meaning. No box frames. No shade blocks (unless as data). The parallelogram progress bar is the signature composition. Separators are middle-dots, not pipes.

This vibe reads as premium, calm, and intentional. It is the default for SaaS dashboards, Telegram inline messages, and any UI where whitespace is part of the design.

## When to Choose

- Proportional-font contexts
- Telegram inline messages and footers
- Progress indicators in clean UIs
- Rating widgets

## When Not to Choose

- Monospace-only terminals (parallelograms may not align)
- Dense data dashboards (needs box frames for structure)
- RTL Arabic primary text (works, but lacks Arabic-native ornaments)

# 05 — Scientific Technical

> Math symbols, Greek letters, dimensional notation. The aesthetic of arXiv, Wolfram, and the lab notebook.

## Signature

`∂ ∇ ∑ ∫ ≈ ≡ α β γ ⟨⟩`

## Philosophy

Precision above all. Every symbol has a defined mathematical meaning. Decorative use is fraud. The vibe is sparse because meaning is dense.

## When to Choose

- Mathematical or scientific documentation
- Engineering dashboards with dimensional units
- API documentation with type notation

## When Not to Choose

- General consumer UIs (most users don't know what ∇ means)
- Status dashboards (too slow to parse)
- Casual chat contexts
